How does the scoring work?

Scores live in this browser only — nothing is uploaded anywhere, because the site is just static files on GitHub Pages with no server behind it. Add each person who's choosing (you, Hattie…) with the + button, tap the stars on the sites that appeal to each of you, and the leaderboard crowns the leader — per person, or combined across everyone.

To pull in someone's scores from another phone, get them to tap Copy my scores link and open it here: you'll be offered to save their scores alongside yours. That's how the combined board gets built — one shared link at a time.
